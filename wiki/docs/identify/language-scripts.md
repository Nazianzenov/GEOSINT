# Languages & scripts

Any visible text is a clue, even unread. Identify the **script** first, then use
**diacritics/unique letters** to pin the language. Reference: [Omniglot](https://omniglot.com/)
(script encyclopedia) and the [Unicode charts](https://www.unicode.org/charts/).[^omniglot]

## Latin alphabet — unique letters & diacritics

| You see | Language (country) |
|---|---|
| **ã, õ** + ç | Portuguese (PT, BR, Angola, Mozambique) — õ also Estonian |
| **ñ** | Spanish |
| **å** | Swedish, Norwegian, Danish (æ/ø → DK/NO; ä/ö → SE) |
| **ø, æ** | Danish, Norwegian |
| **ä, ö** (no å) | German; Finnish (Finnish also y, double vowels: *aa, ii*) |
| **ő, ű** (double acute) | Hungarian — unique worldwide |
| **ř** | Czech — unique; ľ, ĺ → Slovak |
| **ł, ą, ę, ż** | Polish |
| **ğ, ş, ı** (dotless i) | Turkish; ə → Azerbaijani — unique |
| **ț, ș** (comma-below) | Romanian |
| **č, š, ž** alone | Slovene/Croatian/Bosnian/Serbian(Latin), Baltic (+ ė → Lithuanian, ļ/ņ → Latvian) |
| **ð, þ** | Icelandic |
| **ŵ, ŷ**, ll/dd | Welsh |
| **ĉ, ĝ** | Esperanto (signage: rare) / also see Hawaiian ʻokina for Pacific |

## Cyrillic — telling the languages apart

| Letter | Language |
|---|---|
| **ї, є, ґ, and і** | Ukrainian |
| **ў** | Belarusian |
| **ъ** common mid-word | Bulgarian |
| **ә, ғ, қ, ң, ұ** | Kazakh |
| **ө, ү** | Kyrgyz/Mongolian (Mongolia also uses no і) |
| **ћ, ђ, џ, љ, њ** | Serbian/Macedonian (ѓ, ќ → Macedonian) |
| None of the above | Russian |

## Bilingual signage patterns

Dual-script signs localize precisely: French/Dutch (Brussels), French/Arabic (Maghreb),
English/Malay (MY/SG), Spanish/Guaraní (Paraguay), English/Afrikaans/Zulu (ZA),
Russian/local (CIS), English/French (Canada — Québec French-first by law[^ca101]).

[^omniglot]: Ager, S., [Omniglot — writing systems encyclopedia](https://omniglot.com/writing/); Unicode Consortium, [code charts](https://www.unicode.org/charts/).
[^cjk]: Unicode Han unification documentation; for simplified/traditional sets see [Wikipedia: Simplified Chinese characters](https://en.wikipedia.org/wiki/Simplified_Chinese_characters) (sourced to PRC's *Tongyong Guifan Hanzi Biao*).
[^ca101]: Québec, [Charter of the French Language (Bill 101)](https://www.legisquebec.gouv.qc.ca/en/document/cs/C-11) — French predominance on public signage.
