# Internet domains & phone numbers

Shopfronts, vans and billboards constantly display URLs and phone numbers — both are
**centrally registered identifiers** with authoritative databases.

Every delegated ccTLD below (generated from ISO 3166-1 + the IANA root by
`tools/build_refdata.py`, cached locally — re-run to refresh).

Watch for **second-level conventions**: `.com.br`, `.co.uk`, `.com.au`, `.co.za`, `.co.jp` —
the pattern itself is a tell even when truncated. Russia also uses the Cyrillic IDN `.рф`.

## Domestic number formats (no country code shown)

When a local number is painted on a van, its **format** still localizes:

- **0800/0808** freephone + 11-digit `07xxx` mobiles → UK[^ofcom]
- `06 xx xx xx xx` (10 digits, pairs) → France mobiles[^arcep]
- `1-800` + 7-digit local with 3-digit area code in parentheses → North America (NANP)[^nanpa]
- `8 (xxx) xxx-xx-xx` → Russia (domestic trunk "8")
- 4-3-4 grouping starting 04xx → Australia mobiles

**Area codes** within a country are region filters — every national regulator publishes the
allocation table (e.g. [Ofcom UK](https://www.ofcom.org.uk/phones-and-broadband/phone-numbers/numbering),
[NANPA](https://nationalnanpa.com/) for +1, [ARCEP](https://www.arcep.fr/) for France).
